# Backend learning notes — Codex

Lessons follow [the backend checklist](../checklist.md). Each item answers:

1. What is it?
2. Why do we need it?
3. How do we apply / implement / use it?

## Basic / Fundamental → API & Application

Read these lessons in order:

1. [HTTP Fundamentals](basic/api_application/http_fundamentals.md) — the communication protocol.
2. [API / Request-Response](basic/api_application/api_request_response.md) — the application contract and processing flow.
3. [REST API](basic/api_application/rest_api.md) — an architectural style and resource-oriented API design.

Each lesson includes examples and review practice. The task API is an illustrative contract, not a supplied server. Pseudocode is framework-neutral; curl commands require a local implementation listening on port 3000.

Checklist boxes track your learning progress. Mark an item complete when you can explain its three answers and work through its review practice.
