# Message

[Lesson index](../../README.md) · [Previous](2.job.md) · [Next](4.producer.md)

## 1. What is it?

A message is a serialized envelope exchanged between components, like a labeled parcel rather than the workbench that processes it.

## 2. Why do we need it?

Unstructured payloads and missing identity make consumers fail unpredictably, lose compatibility, or repeat effects without recognizing duplicates.

## 3. Under the hood / mechanism / system flow

### 3a. Implementation, state, and cost

An envelope carries stable ID, type, schema version, and payload; transport adds delivery metadata. Serialization copies bytes and imposes size/parse costs. A broker delivery tag is not a globally stable business identifier.

Reference: [Primary documentation](https://www.rabbitmq.com/docs/publishers).

### 3b. Boundaries and lifecycle

Producer encodes → transport stores/routes → consumer authenticates source, checks envelope and payload → handler applies policy → delivery is acknowledged.

## 4. How to apply / implement / use it?

Save as `message_demo.py`; run `python3 message_demo.py`. Standard library only. Assertions cover successful behavior and a rejected, failed, or unsafe case.

```python
import json
def decode(raw):
    if len(raw) > 1024:
        raise ValueError("too large")
    message = json.loads(raw)
    if not isinstance(message, dict) or message.get("version") != 1:
        raise ValueError("unsupported envelope")
    if not isinstance(message.get("id"), str) or not message["id"]:
        raise ValueError("missing identity")
    return message
wire = json.dumps({"id": "evt-1", "version": 1, "type": "OrderPlaced",
                   "payload": {"order_id": 7}}).encode()
assert decode(wire)["payload"]["order_id"] == 7
try:
    decode(b'{"version":2}')
except ValueError:
    pass
else:
    raise AssertionError("unsupported message accepted")
```

This validates only a minimal envelope. Add full payload schemas, authenticated transport, tenant checks, supported-version policy, and safe failure handling. Never deserialize untrusted pickle.

## 5. When should I NOT use this? Trade-offs and anti-patterns

Do not encode an entire database row or secrets by default. Size, versioning, retention, privacy, and compatibility become cross-team obligations.

## 6. How do I know I understand it?

**Blank-page check:** Reconstruct the envelope from memory. Distinguish message ID, aggregate ID, delivery tag, correlation ID, and schema version.

| Constraint change | Predict the failure and response |
| --- | --- |
| Payload adds an optional field | Compatible readers should tolerate it according to contract. |
| Payload changes units | Version or translate explicitly; syntactically valid data may still be wrong. |
