# Infrastructure Layer

[Lesson index](../../README.md) · [Previous](6.application_service.md) · [Next](8.hybrid_architecture.md)

## 1. What is it?

The infrastructure layer implements technical adapters such as database, filesystem, and provider clients, like replaceable wiring behind a room's switches.

## 2. Why do we need it?

Business rules tightly coupled to SQL sessions or provider SDKs become hard to test and expensive to move.

## 3. Under the hood / mechanism / system flow

### 3a. Implementation, state, and cost

Core-facing ports describe required capabilities; outer adapters translate types, errors, and resource lifecycles. Dependency inversion concerns source dependencies, not a ban on runtime calls from the core toward an injected adapter.

Reference: [Primary documentation](https://docs.python.org/3/library/typing.html#typing.Protocol).

### 3b. Boundaries and lifecycle

Composition root builds adapters → injects ports into use cases → adapters perform bounded I/O → technical errors become meaningful application failures.

## 4. How to apply / implement / use it?

Save as `infrastructure_layer_demo.py`; run `python3 infrastructure_layer_demo.py`. Standard library only. Assertions cover successful behavior and a rejected, failed, or unsafe case.

```python
import sqlite3
from typing import Protocol
class TaskReader(Protocol):
    def title(self, task_id: int) -> str: ...
class SQLiteTasks:
    def __init__(self, database):
        self.database = database
    def title(self, task_id):
        row = self.database.execute("SELECT title FROM tasks WHERE id=?",
                                    (task_id,)).fetchone()
        if row is None:
            raise LookupError("missing task")
        return row[0]
def show_task(reader: TaskReader, task_id):
    return reader.title(task_id).upper()
database = sqlite3.connect(":memory:")
database.execute("CREATE TABLE tasks(id PRIMARY KEY, title TEXT)")
database.execute("INSERT INTO tasks VALUES (1, 'learn')")
assert show_task(SQLiteTasks(database), 1) == "LEARN"
try:
    show_task(SQLiteTasks(database), 2)
except LookupError:
    pass
else:
    raise AssertionError("missing data hidden")
database.close()
```

This uses a real SQLite adapter and a structural typing port. Type hints do not enforce runtime authorization or correctness. Production adapters need transaction ownership, connection lifecycle, timeouts, and error mapping.

## 5. When should I NOT use this? Trade-offs and anti-patterns

Do not add abstractions solely to wrap every library method. Avoid leaking ORM objects, provider exceptions, or unbounded query semantics through a supposedly stable port.
