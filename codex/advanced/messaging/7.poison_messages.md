# Poison Messages

[Lesson index](../../README.md) · [Previous](6.message_ordering.md) · [Next](8.advanced_retry_strategies.md)

## 1. What is it?

A poison message repeatedly fails deterministic processing, like a damaged form that no amount of immediate resubmission can repair.

## 2. Why do we need it?

An always-requeued invalid payload wastes capacity, blocks ordered progress, and hides useful work behind a permanent failure.

## 3. Under the hood / mechanism / system flow

### 3a. Implementation, state, and cost

Classify malformed encoding, unsupported schemas, invalid business values, and transient dependency failures separately. Bound decode size, attempts, and diagnostics. Quarantine must preserve safe investigation context without exposing secrets or claiming a successful effect.

Reference: [Primary documentation](https://www.rabbitmq.com/docs/dlx).

### 3b. Boundaries and lifecycle

Receive → size/schema validation → permanent rejection to protected quarantine or bounded transient retry → alert owner → controlled correction/redrive.

## 4. How to apply / implement / use it?

Save as `poison_messages_demo.py`; run `python3 poison_messages_demo.py`. Standard library only. Assertions cover successful behavior and a rejected, failed, or unsafe case.

```python
import json
quarantine, completed = [], []
def handle(raw):
    try:
        if len(raw) > 128:
            raise ValueError("too large")
        message = json.loads(raw)
        if not isinstance(message, dict) or type(message.get("amount")) is not int:
            raise ValueError("amount must be integer")
        if message["amount"] <= 0:
            raise ValueError("amount must be positive")
    except (ValueError, UnicodeDecodeError) as error:
        quarantine.append(type(error).__name__)
        return "quarantined"
    completed.append(message["amount"])
    return "completed"
assert handle(b'{"amount":5}') == "completed"
assert handle(b'{"amount":-1}') == "quarantined"
assert handle(b'not-json') == "quarantined"
assert completed == [5] and len(quarantine) == 2
```

This real bounded decoder models classification only. Production must validate the full envelope and use reliable quarantine transfer with protected payload references, rather than keeping only an exception type.

## 5. When should I NOT use this? Trade-offs and anti-patterns

Do not retry malformed input forever or dump raw sensitive bodies into logs. A consumer bug may poison valid messages; investigate before discarding.

## 6. How do I know I understand it?

**Blank-page check:** Explain which failures can improve without changing the message or code, and which require correction.

| Constraint change | Predict the failure and response |
| --- | --- |
| New producer schema is unsupported | Pause/quarantine under policy and deploy compatibility; rapid retry is not a schema migration. |
| Dependency returns temporary 503 | Treat as transient under a bounded budget, not automatically poison. |
