# Encryption

[Lesson index](../../README.md) · [Previous](3.secrets_management.md) · [Next](5.key_management.md)

## 1. What is it?

Encryption protects data confidentiality using keys, and authenticated encryption also detects modification, like a locked sealed envelope whose seal must verify before its contents are accepted.

## 2. Why do we need it?

Access controls do not prevent exposure from stolen disks, intercepted traffic, or unauthorized ciphertext changes, and encryption without integrity can accept manipulated data.

## 3. Under the hood / mechanism / system flow

### 3a. Implementation, state, and cost

Use maintained protocols/libraries: TLS for transit and appropriate authenticated encryption for application data. AEAD binds plaintext and optional authenticated metadata to a key/nonce; nonce reuse under one AES-GCM key is dangerous. Encryption costs linear byte processing, key access, metadata/tag storage, and recovery complexity; it does not authorize the caller.

Reference: [Primary documentation](https://cryptography.io/en/stable/hazmat/primitives/aead/).

### 3b. Boundaries and lifecycle

Obtain authorized key → allocate a unique nonce under that key's policy → encrypt with contextual AAD → store key ID/nonce/ciphertext → authenticate and decrypt or reject without using plaintext.

## 4. How to apply / implement / use it?

In a new disposable exercise directory, save the Python block as `encryption_demo.py`. This example requires the maintained cryptography library; assertions cover a successful round trip and rejected tampering/wrong authenticated context. No project dependencies need to change.

```sh
python3 -m venv .venv
.venv/bin/python -m pip install cryptography
.venv/bin/python encryption_demo.py
```

The example is validated separately in an isolated environment; cryptography 50.0.2 is the tested version. Keep using a reviewed maintained release rather than treating a learning-note version as a permanent security recommendation.

```python
import os
from cryptography.hazmat.primitives.ciphers.aead import AESGCM
from cryptography.exceptions import InvalidTag
key = AESGCM.generate_key(bit_length=256)
cipher = AESGCM(key)
nonce = os.urandom(12)
aad = b"tenant:shop-1;record:task-1;version:1"
ciphertext = cipher.encrypt(nonce, b"private report", aad)
assert cipher.decrypt(nonce, ciphertext, aad) == b"private report"
tampered = ciphertext[:-1] + bytes([ciphertext[-1] ^ 1])
for candidate, context in ((tampered, aad), (ciphertext, b"tenant:shop-2")):
    try:
        cipher.decrypt(nonce, candidate, context)
    except InvalidTag:
        pass
    else:
        raise AssertionError("unauthenticated data accepted")
```

This uses real AES-GCM from cryptography, not handwritten encryption. It creates one ephemeral key and one nonce for one encryption; it is not durable key management or a multi-writer nonce-allocation policy. Never reuse a nonce with the same key; enforce library/algorithm size and lifetime limits, and preserve key ID, nonce, and AAD contract for recovery.

## 5. When should I NOT use this? Trade-offs and anti-patterns

Do not use reversible encryption for password verification, invent ciphers, disable TLS certificate verification, or store production keys beside ciphertext under identical access. Encryption does not protect data from a compromised authorized application.
